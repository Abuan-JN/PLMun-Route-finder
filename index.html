How the problem-solving agent works Algorithm, modules & data note

Evaluation function

f(n) = g(n) + h(n)

g(n) is the accumulated walking distance from the start. h(n) is the straight-line Euclidean estimate to the goal. The open list always expands the lowest f(n) first.

Search cycle

  1. Load the campus graph and initialise the open list.
  2. Pop the lowest-cost node and add it to the closed list.
  3. Relax each unblocked neighbour; update parent, g and f.
  4. Stop at the goal, then reconstruct the path backwards.

Modules in this build

  • Location management — node metadata & coordinates
  • Path & obstacle management — weighted edges & closures
  • Route search engine — A* with a binary min-heap
  • Route presentation — distance, sequence & directions
